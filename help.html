Quick Help

Common Questions

📄 What format should the JSON key file be in?
It should be the Google Cloud service account JSON key file — the one you download from the Google Cloud Console when setting up a service account. It contains fields like client_email, private_key, etc.
📊 What columns does the retention Excel sheet need?
The master tracker Excel file should contain: Adset Code, ThruPlay %, CTR, CPI, Spend, and retention buckets (0–25%, 25–50%, 50–75%, 75–95%). Contact Mayank if you need the template.
📁 Where do I find my Google Drive Folder ID?
Open the folder in Google Drive and look at the URL. It will look like:
drive.google.com/drive/folders/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs The bold part after /folders/ is your Folder ID.
🤖 Which AI model should I pick?
  • Gemini Flash — Free, fast, great for general narrative analysis.
  • Groq Llama — Ultra-fast inference, great for bulk script comparisons.
  • Claude Haiku — Deepest insight for nuanced, emotional storytelling analysis (paid API key required).
🔒 Is my data safe? Who can see my scripts?
Your JSON key and scripts are processed locally in your Streamlit session — nothing is stored on any external server. Scripts are only sent to the AI provider you choose (Gemini/Groq/Claude) for analysis, as per their API privacy policies.
